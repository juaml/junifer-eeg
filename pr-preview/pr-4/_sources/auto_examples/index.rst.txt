Examples
========

The following are a set of examples, on recordings of the `TUH EEG Corpus
<https://isip.piconepress.com/projects/nedc/html/tuh_eeg/>`_ (TUEG). The TUEG
is distributed by the Neural Engineering Data Consortium (NEDC) of Temple
University under a data agreement: register before using it.
