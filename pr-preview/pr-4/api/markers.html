pydantic model junifer_eeg.markers.EEGBaseMarker¶

Base class for EEG markers.

A marker computes its values along its axes (_AXES, e.g., for each epoch and channel), for one or more features (e.g., the power in each frequency band). The values are then reduced with each of the aggregations, to the dimensionality set by the kind of marker (see ScalarMixin, TopographyMixin and TimeseriesMixin). Each aggregation is stored as a feature of the marker (<name>_<aggregation>).

The base classes of the markers compute the values and cannot be used directly: the concrete markers combine them with one of the mixins.

Parameters:
aggregationsdict of str and list of AggregationStep

The aggregations to compute: a name and the list of steps, one for each axis to reduce. The axes are reduced in the order of the steps (e.g., first across epochs and then across channels, as in Sitt et al. 2014). The order matters unless all the steps are means.

onDataType.EEG or None, optional

The data type to compute the marker on (default None).

namestr or None, optional

The name of the marker. If None, will use the class name (default None).

Create a new model by parsing and validating input data from keyword arguments.

Raises [ValidationError][pydantic_core.ValidationError] if the input data cannot be validated to form a valid model.

self is explicitly positional-only to allow self as a field name.

pydantic model junifer_eeg.markers.EEGContingentNegativeVariation¶

pydantic model junifer_eeg.markers.EEGPowerSpectralDensity¶

Base class for the spectral markers.

The features are computed from the PSD (see PSDEstimator), reducing the frequency axis:

  • <band>: the sum of the PSD in each band, in dB if dB.

  • <band>n: the sum of the normalized PSD (divided by the total power of the estimator frequencies) in each band, if normalized.

  • se: the spectral entropy of the normalized PSD, if spectral_entropy.

  • <edge>: the frequency below which each fraction of the power lies (e.g., the median spectral frequency for 0.5), for each of the spectral_edges.

Parameters:

The frequency bands, as the name and the minimum and maximum frequencies (both included) (default None).

dBbool, optional

Whether to compute the power in the bands in dB (default True).

normalizedbool, optional

Whether to also compute the normalized power in the bands (default False).

spectral_entropybool, optional

Whether to compute the spectral entropy (default False).

spectral_edgesdict of str and float or None, optional

The spectral edges to compute, as the name and the fraction of the power (default None).

aggregationsdict of str and list of AggregationStep

The aggregations to compute. See EEGBaseMarker.

onDataType.EEG or None, optional

The data type to compute the marker on (default None).

namestr or None, optional

The name of the marker (default None).

pydantic model junifer_eeg.markers.EEGSymbolicMutualInformation¶

Base class for the (weighted) symbolic mutual information markers.

The current source density (CSD) of the epochs is computed (if csd), low-passed at filter_freq and transformed into symbols (see symbolize()). The SMI of each pair of channels is the mutual information of their symbols in each epoch, divided by the maximum entropy. The weighted SMI (wSMI) ignores the pairs of identical and opposite symbols. Port of nice.markers.SymbolicMutualInformation. The feature is wsmi or smi, and the values of a channel with itself are 0. The (w)SMI is computed once for the markers with the same parameters (see SMIEstimator).

Parameters:
tminfloat or None, optional

The start of the epochs to use. If None, from the start (default None).

tmaxfloat or None, optional

The end of the epochs to use. If None, until the end (default None).

kernelint, optional

The number of samples of each symbol (default 3).

tauint, optional

The number of samples between the samples of each symbol (default 8).

method{“weighted”, “smi”}, optional

Whether to compute the wSMI or the SMI (default “weighted”).

csdbool, optional

Whether to compute the CSD first (default True).

filter_freqfloat or None, optional

The low-pass frequency. If None, sfreq / kernel / tau (default None).

aggregationsdict of str and list of AggregationStep

pydantic model junifer_eeg.markers.EEGWindowDecoding¶

Base class for the window decoding markers.

For each decoder (a feature), the epochs of condition_a and condition_b are classified from all the channels and samples of the window, with a stratified K-fold cross-validation (shuffled). The classifier standardizes the features, selects the percentile best ones (ANOVA F-value) and fits a linear SVM. The samples are weighted by the inverse of the number of epochs of their condition. The value of each fold is the ROC AUC of the predicted probabilities of the test epochs. The probabilities are calibrated with Platt scaling (a sigmoid fitted with an internal 5-fold cross-validation of the training epochs). Port of nice.markers.WindowDecoding, which computed the AUC of the predicted classes instead.

Parameters:
decoderslist of Decoder

The decoders.

percentilefloat, optional

The percentile of the features to select (default 10).

Cfloat, optional

The regularization parameter of the SVM (default 1.0).

n_splitsint, optional

The number of folds. It is reduced to half the number of epochs if there are fewer (default 10).

seedint, optional

The seed of the shuffling of the folds (default 0).

The aggregations to compute. See EEGBaseMarker.
