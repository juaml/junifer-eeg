4. Built-in components¶

Importing junifer_eeg (with: junifer_eeg in the YAML) registers these components in junifer.

4.1. DataReader¶

EEGDataReader

Concrete implementation for reading EEG data.

4.2. Preprocessors¶

On the continuous data:

EEGPickChannels

Class for picking EEG channels.

EEGSetMontage

Class for setting the standard montage of the EEG data.

EEGFilter

Class for filtering EEG data.

EEGNotchFilter

Class for notch filtering EEG data.

EEGResample

Class for resampling EEG data.

EEGRenameEvents

Class for renaming the events (annotations) of continuous EEG data.

EEGDropEvents

Class for dropping the events (annotations) that follow other events.

Cutting the epochs:

EEGFixedLengthEpochs

Class for cutting continuous EEG data into pseudo-epochs.

EEGEventEpochs

Class for cutting continuous EEG data into epochs around events.

On the epochs:

EEGAdaptiveRejection

Class for the adaptive rejection of bad EEG channels and epochs.

EEGAutoReject

Class for repairing and rejecting bad epochs with autoreject.

EEGAverageReference

Class for re-referencing EEG data to the average.

EEGInterpolateBads

Class for interpolating the bad EEG channels.

4.4. ROIs¶

The ROIs (channel selections) of each montage, used by the picks of the aggregation steps:

Montage

ROIs

GSN-HydroCel-256

scalp, nonscalp, cnv, mmn, p3a, p3b

GSN-HydroCel-128

scalp, nonscalp, cnv, mmn, p3a, p3b

Other ROIs can be registered with EEGROIRegistry.
